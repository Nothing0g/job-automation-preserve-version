# Minimalist theme rationale

The revised interface uses fewer decorative effects and a limited **ink, paper, and muted evergreen** palette. The light theme relies on warm-white surfaces, charcoal text, and one restrained evergreen action color. The dark theme uses layered blue-charcoal surfaces, soft off-white text, and a muted sage action color rather than saturated accents.

This approach follows the recommendation to use dark-grey surfaces rather than pure black to express depth, reserve colour for limited accents, and desaturate colours used against dark surfaces for legibility.[1] It also preserves a distinct light and dark presentation rather than treating aesthetic dark mode as a substitute for usable hierarchy.[2]

| Design decision | Light mode | Dark mode |
|---|---|---|
| Base surface | Warm paper | Blue-charcoal ink |
| Elevated surface | Clean white with a hairline border | Slightly lighter charcoal layer |
| Primary action | Deep evergreen | Soft sage |
| Supporting text | Warm slate | Blue-grey |
| Decorative treatment | Removed gradients, glows, and large orbs | Removed gradients, glows, and large orbs |
